# Getting started

Let's get started with ECLYPSE.

If you want to get to a first successful run quickly, begin with one of the
guided paths below. Once you are comfortable with the workflow, move to the
[concept pages](../concepts/index.md) to customise assets, placement
strategies, events, infrastructure models, and simulation parameters.

## Happy paths

<div class="grid cards" markdown>

-   **[1. Run a minimal local simulation](minimal-local-run.md)**

    ---

    Build a small scenario with the built-in builders, run it locally,
    and retrieve the resulting report.

-   **[2. Inspect and query the report](inspect-results.md)**

    ---

    Learn how to load report frames, choose a backend, and work with the
    collected metrics.

-   **[3. Move to remote emulation](remote-emulation.md)**

    ---

    Run remote services with the MPI or REST communication interfaces and
    understand how the setup differs from a local simulation.

</div>

!!! tip

    If you have not yet installed ECLYPSE, refer to the [Installation](../install.md) page.
    If you want the conceptual map after your first run, continue with
    [Concepts](../concepts/index.md).
