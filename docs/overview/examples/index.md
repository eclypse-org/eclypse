# Examples

The examples section complements the getting-started guides with runnable
scenarios you can inspect and adapt.

The code for the documented examples is available in the
:fontawesome-brands-github:
[examples](https://github.com/eclypse-org/eclypse/tree/main/examples/)
subdirectory of the repository.

<div class="grid cards" markdown>

-   :octicons-megaphone-16: **[Echo](echo.md)**

    ---

    A small service-based application that compares unicast and broadcast
    communication patterns.

-   :octicons-tools-16: **[Off-the-shelf](off_the_shelf.md)**

    ---

    A local simulation composed only from built-in builders, policies,
    and placement logic.

-   :octicons-package-dependents-16: **[SockShop](sock_shop.md)**

    ---

    A microservices application that simulates an online shop and is
    provided in both MPI and REST variants.

-   :octicons-graph-16: **[Grid analysis](grid_analysis.md)**

    ---

    A Ray Tune sweep over infrastructure topologies, update policies, and
    placement strategies.

-   :octicons-iterations-16: **[IO round trip](io_round_trip.md)**

    ---

    An import/export matrix that loads graph files through the default
    IO importers and writes them back through every compatible exporter.

-   :octicons-image-16: **[Image prediction](image_prediction.md)**

    ---

    A remote image-prediction pipeline with custom services, metrics, and
    degradation policies.

-   :octicons-people-16: **[User distribution](user_distribution.md)**

    ---

    A custom metric and update-policy example driven by changing user
    distributions.

</div>
